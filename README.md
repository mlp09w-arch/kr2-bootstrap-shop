# СветДом — магазин настольных ламп

Контрольная работа №2: «CSS-фреймворки: разработка интерфейса на Bootstrap».
Автор: Шкабара Иван Владимирович, группа ЭФБО-01-25.

Предметная область, четыре товара, фотографии и отзывы сохранены из [КР №1](https://github.com/mlp09w-arch/kr1-html-css-shop). Интерфейс собран на Bootstrap 5.3.8. Собственного JavaScript нет: содержимое всех страниц записано в HTML. Для меню, модального окна и FAQ подключён только штатный Bootstrap Bundle, как в демо преподавателя.

## Запуск

Откройте `index.html` в современном браузере. Интернет, установка пакетов и сборка не нужны. Для локального сервера: `python3 -m http.server 8000`, затем http://localhost:8000.

## Bootstrap и обязательные компоненты

Bootstrap 5.3.8 подключён локально, без CDN и jQuery. CSS и Bundle взяты из учебного демо на основе официального compiled release Bootstrap. Bundle включает Popper; лицензия MIT приложена.

- `container`, `row`, `col-*` — сетка всех страниц;
- `navbar`, `navbar-toggler`, `collapse` — единая навигация;
- `card`, `btn`, `badge` — карточки и действия;
- `form-control`, `form-select`, `input-group`, `form-check` — форма;
- `modal` — условия доставки и оплаты;
- `alert` — пояснение и результат HTML-валидации;
- `accordion` — частые вопросы;
- `carousel` — автоматическая смена четырёх фотографий ламп на главной, стрелки и индикаторы;
- `table`, `table-striped`, `table-hover`, `table-responsive` — характеристики;
- `breadcrumb` — навигация по каталогу и карточкам.

Меню, modal, accordion и carousel используют только атрибуты `data-bs-*` и библиотеку Bootstrap. Собственных обработчиков событий, inline-скриптов и `js/main.js` нет.

Собственный `custom.css` подключён после Bootstrap и задаёт оформление магазина. Сетка остаётся на Bootstrap: одна колонка карточек на телефоне, две на планшете, четыре на широком экране главной. Подвал доходит до нижнего края окна на коротких страницах и при уменьшении масштаба; длинные страницы прокручиваются обычным образом.

## Каталог и карточки

Каталог показывает все четыре модели. Фильтры — явно обозначенный статический макет с отключёнными полями. Фильтрации и сортировки нет.

Каждая модель открывается по собственной HTML-ссылке с готовыми фотографией, описанием, ценой и таблицей. URL-параметры и JavaScript для показа товара не нужны. Кнопка заказа ведёт в общую форму; модель выбирается в ней вручную.

## Учебная форма без собственного JavaScript

Проверку выполняет браузер через `required`, `type="email"`, `pattern`, `minlength`, `min` и `max`. Адрес доставки виден всегда, при самовывозе его можно не заполнять. Автоматического расчёта суммы нет: рядом показаны цены и условия доставки.

Форма находится в открытом немодальном `<dialog open>` и использует `method="dialog"`. Кнопка «Проверить заявку» сначала запускает HTML-валидацию. При корректном заполнении браузер закрывает этот блок формы. CSS показывает расположенное следом сообщение о завершении проверки и ссылку для повторного заполнения. Данные формы не передаются по сети и не помещаются в URL. Это стандартное поведение HTML, собственного JS для него нет.

Реальные заявки, оплата и backend отсутствуют. Цены, контакты и характеристики демонстрационные. Подробные характеристики «Лайм» сохранены из КР №1; для остальных моделей показаны только имеющиеся сведения.
