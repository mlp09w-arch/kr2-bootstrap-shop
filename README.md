# СветДом — магазин настольных ламп

Контрольная работа №2: «CSS-фреймворки: разработка интерфейса на Bootstrap».
Автор: Шкабара Иван Владимирович, группа ЭФБО-01-25.

Предметная область, фотографии и четыре товара сохранены из [КР №1](https://github.com/mlp09w-arch/kr1-html-css-shop). Интерфейс заново собран на Bootstrap 5.3.8. Демо преподавателя использовано как пример подключения компонентов, а не как готовая контрольная работа.

## Запуск

Откройте `index.html` в современном браузере. Интернет, установка пакетов и сборка не нужны. Можно запустить `python3 -m http.server 8000` в папке проекта и открыть http://localhost:8000.

## Bootstrap и обязательные компоненты

Используется Bootstrap 5.3.8 локально, без CDN и jQuery. CSS и Bundle взяты из учебного демо, которое использует официальный compiled release Bootstrap. Bundle включает Popper. Bootstrap распространяется по MIT; лицензия включена.

- `container`, `row`, `col-*` — основа раскладки на всех страницах;
- `navbar`, `navbar-toggler`, `collapse` — единая раскрывающаяся навигация;
- `card`, `btn`, `badge` — товары и варианты действий;
- `form-control`, `form-select`, `input-group`, `form-check` — форма заявки;
- `modal` — условия доставки и оплаты; открытие/закрытие через `data-bs-*`;
- `alert` — пояснение формы, пустая выдача, результат проверки;
- `accordion` — дополнительный компонент с частыми вопросами;
- `table`, `table-striped`, `table-hover`, `table-responsive` — характеристики;
- `breadcrumb` — навигация по каталогу и карточке.

Собственный CSS задаёт фирменные цвета, изображения и фокус, не заменяя сетку Bootstrap. `custom.css` подключён после фреймворка. Сетка карточек: 1 колонка на телефоне, 2 на планшете, 4 на широком экране главной. Каталог имеет боковой фильтр на больших экранах.

## Самостоятельные доработки

- Перенос магазина «СветДом» с сохранением четырёх моделей, цен и фотографий.
- Собственное оформление с зелёной палитрой и крупным hero.
- Рабочие фильтры по категории и максимальной цене, сортировка и сообщение пустой выдачи.
- Один шаблон карточки товара для всех четырёх моделей: `product.html?model=green|beige|black|bird`. Без параметра или с неизвестной моделью открывается «Лайм».
- Передача выбранной модели в заявку через URL.
- Расчёт количества и доставки: самовывоз бесплатно; курьер 350 ₽, от 7 000 ₽ бесплатно.
- Поле адреса требуется только для курьера; HTML-валидация имени, почты, телефона, количества и согласия.
- Учебный результат формы без перезагрузки и передачи персональных данных.
- Дополнительная страница контактов, хлебные крошки, якоря, видимый фокус, skip-link и поддержка уменьшения анимации.

Цены и контакты демонстрационные. Backend, оплата и реальное оформление заказа отсутствуют. Полные характеристики «Лайм» взяты из КР №1; для остальных моделей показаны только имеющиеся сведения. Статические HTML-страницы содержат базовое содержимое, JavaScript дополняет выбор товара и интерактивность. Bootstrap JS отдельно обслуживает меню, modal и accordion.

## Что показать на защите

1. Открыть главную и объяснить сетку `container → row → col-*`.
2. Сузить окно и раскрыть меню.
3. В каталоге выбрать «Классическая», затем цену до 6 000 ₽: остаётся «Классика»; сбросить фильтры.
4. Открыть любую модель, проверить фотографию, цену, характеристики и переход к заявке.
5. Открыть/закрыть модальное окно, раскрыть FAQ.
6. В заявке выбрать «Лайм», количество 1 и курьера: 3 840 ₽; количество 3: 10 470 ₽ и бесплатная доставка.
7. Показать обязательные поля, проверку e-mail, условное поле адреса и сообщение учебной проверки.
8. Объяснить отличие фреймворка, собственных стилей и собственного JS.
